# Project Limitations

This project is intentionally educational.

---

## Current limitations

- Educational ACMG approximation
- Five evidence criteria only
- No authentication
- No database
- No user accounts
- No caching
- Single-user memory storage
- No batch processing
- No VCF upload

---

## Biological limitations

Only coding HGVS notation is supported.

Not currently supported

- protein HGVS
- genomic HGVS
- mitochondrial HGVS

---

## Clinical limitations

This software

- is not validated
- is not FDA approved
- is not CAP/CLIA compliant
- must never be used for patient care
